Plan #4 - Prevent data loss if GitHub sync fails silently
#4 - Prevent data loss if GitHub sync fails silently
What & Why
db.json is pushed to GitHub every 45 seconds. If the push fails (bad token, rate limit, network) the error is only logged to the server console — the admin panel shows no warning and db.json diverges from GitHub silently. On the next cold boot the stale GitHub copy is restored, losing recent changes.

Done looks like
The admin panel shows a "Last sync" indicator with a warning badge when the last push failed
Failed pushes surface a toast or status badge in the panel rather than only appearing in server logs
Optionally: retry logic with exponential back-off for transient failures
